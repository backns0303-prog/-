품평/프로젝트 관리 대시보드 소개

엑셀로 흩어진 수주, 진행, 재고 데이터를 업로드하고 Google Sheets를 허브로 정리한 뒤, 캘린더 중심 화면에서 바로 읽고 판단하게 만든 운영형 대시보드입니다.

핵심 메시지
1
업로드부터 조회, drill-down, 재다운로드까지 한 흐름
Problem
파일은 많은데 흐름은 끊겨 있었습니다
수주, 관리, 진행, 재고를 따로 보던 구조를 하나로 묶었습니다.
Promise
현업 판단 속도를 높이는 화면
숫자 표시가 아니라 어디를 먼저 봐야 하는지 알려주는 도구입니다.
Why

왜 이 앱이 필요했는가

기존 업무의 불편

  • 데이터가 여러 엑셀 파일과 시트로 분산되어 있었습니다.
  • 수주 정보, 관리 정보, 생산 진행, 재고 현황을 따로 봐야 했습니다.
  • 일정 확인과 품목 확인이 한 번에 이어지지 않았습니다.

이번 앱의 목표

  • 업로드만 하면 최신 데이터를 자동 반영합니다.
  • 월별 일정과 프로젝트 현황을 직관적으로 보여줍니다.
  • 필요한 수주건만 즉시 drill-down 할 수 있게 만듭니다.
핵심은 데이터를 더 많이 보여주는 것이 아니라, 같은 데이터를 더 빨리 읽고 더 빨리 다음 행동으로 이어지게 만드는 것입니다.
Flow

업무 흐름을 하나로 연결했습니다

이 앱은 단순 조회 화면이 아니라, 업로드부터 현업 전달까지 이어지는 운영 흐름 전체를 다룹니다.

데이터 흐름도

`.xls`, `.xlsx` 원본 다건 입력

유형별 최신 워크시트 생성
Logic
최신 시트 자동 병합
수주·관리·진행·재고 연결
View
카드와 캘린더 조회
요약과 일정 중심 탐색
Action

drill-down 후 `.xlsx` 내보내기
핵심 1원본 파일을 버리지 않고 그대로 활용
핵심 2중간 허브는 Google Sheets가 담당
핵심 3마지막 출력도 다시 엑셀로 연결

발표에서 이렇게 설명하면 좋습니다

  • 입력부터 출력까지 하나의 파이프라인으로 설계했다는 점을 강조합니다.
  • 사람이 여러 파일을 옮겨 다니던 과정을 시스템 흐름으로 바꿨다고 설명합니다.
  • 조회 화면이 끝이 아니라, 다시 실무 파일로 이어지는 점을 짚습니다.
Scene 1

상단 요약 카드는 숫자가 아니라
탐색의 시작점입니다

주간/월간/임박 건수

사용자가 오늘 먼저 봐야 하는 영역을 요약해서 제시합니다.

클릭 기반 이동

카드를 누르면 관련 수주건만 곧바로 상세 조회 상태로 연결됩니다.

의사결정 보조

숫자 나열이 아니라 지금 주목해야 할 구간을 먼저 읽게 합니다.

발표 포인트: “이 화면은 보고서가 아니라, 사용자의 시선을 우선순위로 유도하는 장치입니다.”
Scene 2

오버레이 캘린더로 일정과 프로젝트를
한눈에 겹쳐서 봅니다

캘린더 중심 탐색

  • 월 단위로 프로젝트 일정을 겹쳐서 보여줍니다.
  • 사업 구분, 조회 월, 제품군 조건에 따라 즉시 필터링합니다.
  • 여러 수주건을 함께 선택해서 비교할 수 있습니다.

현업에서 확장 있는 이유

  • 어느 시점에 프로젝트가 몰려 있는지 빠르게 파악됩니다.
  • 병목 가능 구간이나 우선순위 조정이 쉬워집니다.
  • 세부 화면으로 들어가기 전에 일정 관점에서 큰 그림을 잡게 합니다.
커스텀 컴포넌트로 구현되어 일반적인 표 기반 화면보다 직관적인 상호작용을 제공합니다.
Scene 3

상세 패널에서는 수주건, 품목, 재고가
하나의 흐름으로 이어집니다

기본 정보

시작일, 종료일, 포함 수주건 수, 사업소 같은 핵심 정보를 바로 확인합니다.

생산/재고

계획, 실적, 잔량, 현재고, 재고금액을 함께 봅니다.

세부 필터

관련 세부 수주건을 체크박스로 선택해 필요한 것만 남길 수 있습니다.

재활용

필터링한 품목 결과를 다시 `.xlsx`로 내보내 현업 전달에 활용합니다.

발표 포인트: “보기에서 끝나지 않고, 다시 실무 파일로 내보낼 수 있다는 점이 운영 도구로서 중요합니다.”

설명 포인트

  • 화면 아래에 별도 데이터 파이프라인 층이 있다는 점을 보여줍니다.
  • 중간 로직 층에서 최신 시트 선택, 필터, 캐시가 처리된다고 설명합니다.
  • 그래서 사용자는 복잡한 원본 구조를 몰라도 결과만 읽을 수 있다고 정리합니다.
데이터 정리가 안정적이어야 화면의 신뢰도도 올라갑니다. 이 앱의 품질은 UI보다 먼저 데이터 파이프라인에서 결정됩니다.
Tech

구현하면서 특히 신경 쓴 기술 포인트

Streamlit 빠르게 구현하면서도 실제 운영용 화면으로 다듬기 좋은 기반
Custom Components 캘린더와 요약카드에 맞춤형 상호작용을 부여
Cache `st.cache_resource`, `st.cache_data`로 반복 조회 속도 개선
Parallel Load 스프레드시트 로딩을 병렬화해 체감 대기 시간 단축
Editable Rules 키워드와 기준값 일부를 화면에서 관리 가능

즉, 데모 수준이 아니라 실제 사용 중 반복 조회와 운영 편의까지 고려한 구조입니다.

Impact

기대 효과는 명확합니다

업무 속도

  • 엑셀 파일을 하나씩 열어보는 시간이 줄어듭니다.
  • 일정과 품목 이슈를 더 빨리 발견할 수 있습니다.
  • 회의나 공유 때 같은 화면을 기준으로 이야기할 수 있습니다.

업무 연결성

  • 업로드와 조회가 같은 도구 안에서 이어집니다.
  • 분석 결과를 다시 엑셀로 내보낼 수 있습니다.
  • 기존 엑셀 기반 업무를 유지하면서도 읽는 방식은 개선됩니다.
한마디로, 기존 데이터를 버리지 않고도 더 빠르게 읽고 더 빠르게 공유하게 만드는 실무형 대시보드입니다.

소개 문장

이 대시보드는 엑셀 업로드, Google Sheets 정리, 일정 중심 조회, 수주건 상세 확인, 품목 재다운로드까지 실제 업무 흐름을 한 화면 경험으로 연결한 앱입니다.

HTML 발표 파일입니다. 브라우저에서 열어 발표하고, 인쇄 시 각 슬라이드가 한 페이지씩 PDF로 저장되도록 구성했습니다.
